# Susheetha M — Portfolio Website

## Preview locally
1. Extract the ZIP file.
2. Open the `susheetha_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `susheetha-portfolio`).
2. Upload `index.html` and the `assets` folder (keep the folder structure unchanged).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Before publishing
- Replace `[Phone Number]` and `[Email Address]` in `index.html`.
- Confirm all project and role descriptions are accurate.
- The book-publishing item is described as participation in a world-record-associated initiative; update it if official recognition is confirmed.
